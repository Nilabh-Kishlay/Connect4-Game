# 🎮 Connect 4 Game

An interactive Connect 4 game built using HTML, CSS and JavaScript.

## 🚀 Features

- Two-player gameplay
- Red vs Green discs
- Automatic winner detection
- Draw detection
- Restart game button
- Responsive and simple UI
- Pure HTML, CSS and JavaScript (No libraries)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

```bash
Connect4-Game/

```

## 🎯 How to Play

1. Open the game in browser
2. Red player starts first
3. Click any column to drop disc
4. First player to connect 4 discs wins
5. If board fills completely, game becomes draw
